# Structure Wand Mod

Fabric mod for Minecraft 1.21.4 with structure placement and preview features

## Features

- Structure Wand item with GUI for house style selection
- Real-time preview with terrain adaptation
- Instant placement of structures

## Requirements

- Minecraft 1.21.4
- Fabric Loader
- Fabric API

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/structure-wand-mod/releases)
2. Place the mod in your `mods` folder
3. Launch Minecraft with Fabric Loader

## Usage

1. Craft or obtain the Structure Wand item
2. Right-click to open the house style selection GUI
3. Select a house style and preview the structure
4. Place the structure instantly

## Configuration

The mod does not have a configuration file. All settings are hardcoded in the mod.
